# Primer servidor web con Node.js y Express

Servidor HTTP básico construido con Node.js y Express como parte de una actividad académica sobre desarrollo Back-End.

## Rutas disponibles

- `GET /` — mensaje de bienvenida.
- `GET /proyecto` — información básica del proyecto en formato JSON.

## Cómo instalar y ejecutar

1. Clona este repositorio o descarga el código.
2. Instala las dependencias con el comando: `npm install`
3. Inicia el servidor con el comando: `npm start`
4. Abre tu navegador o Postman en:
   - http://localhost:3000/
   - http://localhost:3000/proyecto
